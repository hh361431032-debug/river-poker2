河畔牌局 v6 更新

本版基于上一版 v5（头像 + 座位倒计时）继续增加“玩家互动投掷”功能：

1. 点击牌桌上其他玩家的座位，可以选中目标。
2. 选择投掷物：
   - 🥚 鸡蛋：10 筹码
   - 🍅 番茄：15 筹码
   - 🧱 板砖：30 筹码
3. 点击后会立即扣除自己的筹码，并在牌桌上播放飞行动画。
4. 所有玩家都能看到投掷动画和系统日志。
5. 自己筹码不足时，对应按钮自动禁用。
6. 不能向自己投掷。
7. 只有正式牌局（playing）期间可以投掷。

数据库：本功能不新增数据库字段，投掷事件直接随现有 poker_rooms 的房间 state 同步。

部署：保留你原来的 .env.local，不要覆盖它。然后正常 npm install / npm run build / git push。
